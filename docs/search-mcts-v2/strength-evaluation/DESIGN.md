# Predeclared design

Declared on October 9, 2026, before running any new strength games.

The primary estimand is challenger score against optimized MCTS 400 over a
balanced mixture of uniformly generated legal-column, nonterminal histories
at 2, 5, 8, 11, 14, 17, 20, and 23 plies. This is an artificial randomized
position distribution, not perfect play, human play, or empty-board strength.
It includes both move parities, tactical advantages, different column heights,
and full-column structures. Reject only terminal histories and exact duplicate
histories, never moves, outcomes, or timings from tested agents. Each opening
has a domain-separated generator RNG; histories and rejection counts are saved.
Uniqueness conditioning introduces a small sampling dependence at short lengths;
different histories can transpose into the same board. No mirroring or repeated
seed replication will be counted as another independent opening.

There are 128 opening/seed clusters per primary matchup: 800, 2,000, 5,000,
and 10,000 simulations versus optimized 400. Each cluster has both challenger
colors: 256 games per condition, 1,024 primary games. All five budgets also play
Negamax 4 and 6 on the first 32 declared main openings (four per length), both
colors: 64 games per condition, 640 secondary games. Secondary inference is
exploratory and has wider uncertainty; it does not carry the primary power
claim. No direct high-budget versus high-budget matches are planned; differences
in their performance against a shared opponent are not direct head-to-head scores.

Role-specific, independently initialized 128-bit seeds are generated by SHA-256
domain separation from master seed 2026100903. The challenger and opponent seeds
are reused across colors and conditions for one opening, with fresh Random
objects per game. Streams persist within each game; budget changes consume
different numbers of RNG draws and divergent games cannot share an identical
future random trajectory. Negamax has deterministic center-order ties and uses
no RNG; its unused assigned seed is nevertheless recorded. The public API instead
initializes RNG per ply; this harness evaluates agents with persistent streams,
not an exact public-session replay. Caller isolation and legal moves are checked.

The 112-game preflight uses four separately seeded opening/seed pairs excluded
from inference, at 2/8/17/23 plies,
both colors for all fourteen conditions. It checks correctness, actual runtime,
and extrapolated main-run cost. No result selects or changes openings. A 300-second
preflight cap and 1,800-second cumulative main-run cap are fixed. Budget checks
occur between games, so an in-progress game may overrun the cap by one game.
If projection exceeds the cap, preserve the plan and report incompleteness;
do not increase samples or the cap to seek favorable outcomes. Profiling has a
separate 600-second target; tests and analysis are outside search-run caps.

Games are serial, interleaved by opening and condition, with rotated condition
order and alternating first color. Each complete game is fsynced to JSONL.
Resume validates the configuration/source/runtime and replays all saved games
before skipping them. Interruptions/errors are separate incomplete-attempt records;
the first error stops an invocation. A retry starts that game with its original
seeds. Evidence corruption fails closed rather than silently dropping a line.
Use one writer; no concurrent harness processes. A hard process kill may require
explicit repair of a partial trailing line from a preserved copy.

Analysis averages both color scores per opening, resampling whole openings within
fixed opening-length strata, with 10,000 deterministic bootstrap replicates.
Report W/D/L, raw score, color scores, per-opening challenger-minus-opponent score,
95% percentile intervals, and paired cross-budget score differences on shared
openings. Primary evidence of improvement requires a lower 98.75% interval above
0.5 (Bonferroni four-comparison family), alongside unadjusted 95% intervals.
This is approximate bootstrap coverage, not a formal exact test. Secondary and
cross-budget intervals are descriptive/exploratory without multiplicity claims.
No Elo estimates. Unpaired games count in descriptive tallies but not inference.

Profiling uses an independent, predetermined set of sixteen random histories
(two per declared length), plus the existing empty, near-opening, and late
fixtures. All positions remain included, even tactical simulation bypasses.
Budgets are 400/2,000/5,000/10,000. Each condition gets one discarded warm-up
and seven interleaved fresh-seed samples. Time actual production choose_move
without hooks. Separately capture executed simulations, retained-tree nodes and
depth, current/peak tracemalloc bytes and largest retained allocation sites;
run cProfile with caller-level selection, rollout, expansion-component and
backpropagation measurements. Instrumented timings are not latency estimates.
No production changes or speculative optimizations are authorized by results.
