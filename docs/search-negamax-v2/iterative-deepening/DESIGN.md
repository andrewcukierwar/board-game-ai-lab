## Four independently attributable variants

- A/direct: unchanged baseline fixed-depth decision.
- B/hints: one complete preparatory search at target minus two (minimum one),
  then a fresh full-depth score TT, with move-only hints from that preparation.
- C/iterative: complete searches at 2,4,...,target for even targets; 1,3,...,target
  for odd targets. Fresh score TT each iteration, no cross-depth hints.
- D/combined: C's schedule, with move-only hints from the immediately preceding
  completed iteration. No extra schedule ablations are planned.

Two-ply increments keep the heuristic perspective/parity aligned and avoid
paying for every intermediate horizon. B isolates the single closest compatible
shallower horizon; C measures the overhead of the same schedule without hint
reuse. Targets one/two have no preparation. Every iteration searches ALL legal
root moves with independent full windows in historical center order. No root
reordering, aspiration, new pruning, early/partial return or timeout decisions.

## Hint identity and lifetime

Use packed full identity `X | (O << 49) | (mover << 98)`, with no depth.
The cache is a fresh per-decision dictionary mapping identities ONLY to Python
integer columns. Export searched moves from the preceding iteration's regular
TT (EXACT and bounds may suggest ordering, never supply a cross-depth value).
Replace the entire hint snapshot after each iteration; do not accumulate older
horizons or write hints during the final search. Export costs and cache release
are inside complete-decision timing. Retain only the previous snapshot while
searching. Same-depth TT hints take precedence, immediate wins outrank hints.
Require exact `int` type, 0..6, and a non-full column before use; reject booleans,
floats, foreign objects, absent and full-column hints. No score, bound, solved
flag, depth, skipped move or partial-search state is carried in this cache.
The ordinary packed score TT identity and bound interpretation are unchanged.

## Resource preflight and computational budget

Before the main run, perform one untraced and one traced decision for every
variant on empty, near-opening, seeded-04 and tail at D8/D10. Allow main only
if untraced complete decisions <=10s and traced peaks <=256 MiB. Project main
cost from these conservative means with a 2x allowance; budget 7,200s main,
600s diagnostics/audit, 600s full tests/report preparation (8,400s compute).
Preserve a failed preflight, do not reduce the distribution based on outcomes.

Experimental D12 is diagnostic only. After main, gate a single bounded-resource
fresh-process A/D12 empty probe using a 30s external process deadline and 512
MiB OS memory limit where supported (a process kill is an INCOMPLETE diagnostic,
never a search result). Proceed with four-way D12 on empty, near-opening,
seeded-04 and tail only if the empty probe completes <=10s, observed high-water
RSS <=256 MiB, and projected four-way timings/traces fit the remaining 600s
diagnostic allowance. Seven matched timing samples and one traced memory run
per variant there; require whole root-score parity. Otherwise report D12
infeasible within this budget, without raising public caps.

## Measurement

Serial matched, interleaved trials: one discarded warm-up per condition/variant,
seven samples, variant order rotates by repetition AND condition index.
Measure whole ordinary choose_move, including state conversion, intermediate
root searches, export, table construction and release; game creation, wrappers,
memory sizing and variant selection outside timing. Wall perf_counter and
process CPU time; use medians, absolute milliseconds, A/new speedups, raw
samples and variability. Equalize each table class with 64 constructor warmups.
Record all iteration counters and final-iteration nodes separately from totals.

Separate diagnostic run counts per-iteration heuristic leaves, hint lookups,
legal/invalid suggestions, suggestions changing the first ordered move, loop
cutoffs on the first move, and cutoffs on a hinted first move. A legal suggestion
is not evidence of benefit by itself; changes in final and total nodes/leaves
and complete latency determine ordering effectiveness. Instrumented latency
never enters estimates. TT entries report per iteration, summed stores retained
at iteration end, and final retained count; sums are NOT simultaneous occupancy.

Two tracemalloc runs per condition/variant without retaining intermediate TTs.
Retain final table and its previous-horizon hint snapshot only for diagnosis;
size unique reachable objects with separate score-TT/hint attribution, counting
shared objects once. Record traced current and peak including intermediate
export overlap. Fresh subprocess RSS/high-water on the four preflight boards at
D10 for all variants; interpreter/allocator included, no memory-ceiling claim.
Record hardware/runtime/load; do not stop other host activity.

## Correctness and selection thresholds

Mandatory ordered final root-score vector and selected move equality on EVERY
run against A; self counters deterministic within each variant, cross-variant
counters may differ. Full completion, stable root ties, depth/mover-sensitive
TT identities and EXACT/LOWER/UPPER bounds, terminal-before-leaf values,
invalid/stale hint rejection, no caller mutation, exact incremental state and
nested/root exception restoration. Independent array unpruned minimax at
tractable depths includes horizon differences, transpositions, all bounds,
forced wins/losses, nearly full boards and draws. Preserve all earlier tests;
full backend suite with dotenv/explanations disabled and empty provider key.

For default eligibility ALL must pass on non-tail conditions:

1. Broad geometric complete wall speedup >=1.15x; >=75% broad conditions faster.
2. All-condition geometric speedup >=1.05x; sum of median latencies <=90% of A.
3. Each condition <=1.20x A latency OR added cost <=0.25ms. All expensive
   conditions (A >=50ms, INCLUDING tail) <=1.20x A and total nodes <=1.25x A.
4. Each retained and traced peak <=1.25x A OR added <=64 KiB; summed retained
   bytes for broad conditions <=1.15x A. CPU sum <=95% of A.
5. Exact correctness, deterministic completion, full backend validation.

Select lowest summed median latency among eligible variants; otherwise preserve
direct production behavior and commit validated experiments/negative findings.
No result-driven tuning, fixture exclusion or relaxed thresholds. Report
limitations, all regressions and feasibility separately from default selection.
