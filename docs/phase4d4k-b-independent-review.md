- The deployment script defaults to torch-free lite mode, explicitly overrides runtime AlphaZero enablement, checks architecture and commit provenance, runs candidate smoke checks before stopping production, preserves the old container/environment for rollback, and restores it on failed cutover. Twelve mocked tests exercised opt-in/default mode, candidate failures, failed cutover, foreign-container refusal, and rollback. The reviewer never ran the actual deployment script.
