At the pilot-selected2048 updates, cumulative shrink is0.0061438% versus0.0614211%, only0.0552807% additional relative shrink (ratio of multipliers). At1024 updates the additional shrink is0.0276442%. This calculation isolates direct decoupled decay, without claiming optimizer/training indirect effects are identically zero. Biases would not decay under the existing grouping. At final milestone compare treatment with both final control and initial checkpoint. Tactical immediate-win and safe-response categories separately: pass if point difference>=−.03 and95% lower>=−.10 in each seed/category/comparator; regression if point<=−.05 and95% upper<0; otherwise unresolved. Strength supporting pass if point difference>=−.05 and95% lower>=−.15 in both seeds/comparators; regression if point<=−.05 and95% upper<0; otherwise unresolved. Forty pairs are underpowered for small strength differences, so a supportive result cannot prove preserved strength. Raw-policy gates reported descriptively with same tactical margins. Zero baseline or improved exact MSE alone does not decide success. Primary pass plus safeguarded, qualified supporting evidence can justify one next validation study, never promotion here. Any regression overrides favorable MSE. If primary unclear/negative or safeguards unresolved, retain CNN and recommend one different value-learning hypothesis, not expanding this study.
